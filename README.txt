TELLO.KZ — production-ready starter
====================================
Настоящая архитектура:
Node.js + Express + PostgreSQL + JWT + bcrypt + Multer + Docker.

Локально через Docker:
1. Установить Docker Desktop.
2. В этой папке выполнить:
   docker compose up --build
3. Открыть http://localhost:3000

База создаётся автоматически и изначально ПУСТА:
- нет тестовых пользователей;
- нет тестовых объявлений;
- нет сообщений;
- нет избранного.

Есть:
- регистрация/вход;
- общая PostgreSQL база;
- реальные объявления;
- загрузка фото;
- избранное;
- сообщения;
- дизайнерский кабинет;
- удаление своих объявлений;
- фильтры;
- REST API;
- Docker;
- постоянные volumes для БД и фотографий.

Публикация:
1. Арендовать VPS/облачный сервер с Docker.
2. Залить проект.
3. Сменить POSTGRES_PASSWORD и JWT_SECRET.
4. Запустить docker compose up -d --build.
5. Поставить reverse proxy (Nginx/Caddy) и HTTPS.
6. Направить DNS домена tello.kz на IP сервера.
7. Для большого трафика добавить S3-compatible storage для фото и резервные копии PostgreSQL.

Примечание:
Домен tello.kz сам по себе не регистрируется этим архивом — домен нужно отдельно приобрести/настроить у регистратора.
